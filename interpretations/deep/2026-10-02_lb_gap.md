# Deep LB gap: reference pipeline vs ours (2026-10-02)

Question (bd `megspeech-7gf.21`): context-v1 scored 0.385 on the public LB against a reference near 0.47 and a
frontier at 0.765. Which pipeline difference carries the gap?

## Answer

The gap that opened the issue is **closed**, and the mechanism was holdout **context**, not any
preprocessing or capacity axis. Holdout sentence rows are 1–9-word read sentences with every word's onset,
OOV included. The old *gap* grouping (vocabulary words only, spans split at onset gaps) trained a context the
holdout never shows. Moving training and selection to whole PNPL sentences (`--data.grouping sentence`) and
selecting on the sentence-span novel-by-text ruler took LB from 0.385 to 0.567 (single seed). A 4-seed
ensemble took it to **0.637**.

| model | local ruler (n) | public LB |
|---|---|---|
| context-v1 (gap path) | 0.525 (gap novel, n=1479) | 0.385 |
| sent40-s0 | 0.617 (sentence novel, n=2512) | 0.567 |
| ens-sent40-s0123 | 0.638 (n=2512) | 0.637 |
| reference baseline (deep, B `RESULTS.md:18`) | val 0.629 / test 0.567 | holdout 0.467 |

Two observations:

- We are now about 17 points above the reference holdout number.
- The remaining 13-point gap to the frontier (0.765; 10th place is 0.717) is **not** explained by anything the
  reference does differently. The reference is weaker, so the diff below lists *untested axes*, not causes.

Ensembling transfers about 3× better to the LB than to local validation:

- **LB:** +0.070.
- **Local:** +0.021.
- **Hypothesis:** holdout rows are noisier, single-pass sentence epochs, so variance reduction is worth more
  there.
- **Evidence:** one 4-member ensemble, n=1. This is a hypothesis, not a result.

## Pipeline diff

**Notation:**

- **B** = baseline repo `external/2026-pnpl-competition-baselines`. It runs D's grid, so B = D unless noted.
- **D** = d'Ascoli, `external/dascoli-word-decoding`.
- Cites are in the agent transcript. Mechanisms are paraphrased; no code is copied.

| axis | reference | ours | issue |
|---|---|---|---|
| Band-pass | 0.1–40 Hz (training only; B's holdout path skips it) | decimation anti-alias only | 25.12 |
| Baseline | mean of 0–0.5 s | mean of the whole valid window | 25.12 |
| Scaling | RobustScaler per whole recording (B holdout: per subject archive) | Scaler from training windows; per-recording opt-in (`standardised`) | 25.4 / 25.12, arm queued |
| Clamp | ±5 | ±5 | same |

| Context transformer | 16 layers × 16 heads × 1024, rotary | 4 × 4 × 256, sinusoidal onset clock | 4te.1, arm `sent40-w512-s0` queued |

| Ensembling | none | geometric mean of members | 7gf.20 |

## What this does and does not rule out

- **Ruled out as the 0.385 cause:** the reference's scaling, filtering and window. Our gap closed without any of
  them.
- **Not ruled out as frontier levers:** capacity, SigLIP/OOV targets, and subjects 1–32 (+25.5). The reference
  ties capacity to SigLIP and lr 1e-4, so a wide arm on our softmax recipe failing would retire only that
  pairing, not depth.
- **Ruler caveat:** the ruler is narrative (Sherlock1 + TheMoth), while the holdout is read sentences. MOCHA
  validation is recited TIMIT and therefore leaked, so no read-domain ruler exists. Transfer is measured at about
  1.0 for ensembles and 0.92 for single seeds, based on 3 submissions.
