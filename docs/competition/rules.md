# PNPL Competition 2026 — rules as published (checked 2026-10-05)

Sources: libribrain.com/editions/2026/rules/ and /faq/ (fetched 2026-10-05). The Kaggle Rules tab is not
reachable from the Kaggle CLI and has not been captured.

Quoted from the rules page:

- "Final rankings are determined on independent holdout data recorded with stimuli that are entirely different
  from anything released to participants"
- Top-ranking teams must provide "runnable model checkpoints"; teams may be asked for "training code so we can
  verify no cheating took place"
- "Submissions must beat the reference baselines to be eligible for prizes"; a team wins prize money once.

Not addressed on either page: external data, pretrained models, language models, use of stimulus text,
test-time adaptation. The FAQ has no question on these. Clarification channel: libribrain@robots.ox.ac.uk or
the competition Discord.
